The Problem

Today, Taboola feed widgets on NBC News article pages are styled through manually configured custom CSS properties and custom UI modes. This process requires:

  • 1. A Taboola account manager to create a custom mode (UI template) for NBC's placements
  • 2. Publisher or Taboola engineers to write CSS overrides targeting internal Taboola classes (.trc_rbox_*, .tbl-*)
  • 3. Manual coordination whenever NBC updates fonts, colors, or layout patterns on their editorial pages
  • 4. Ongoing CSS specificity battles as both Taboola and NBC update their styles independently

Why Web Crawler Brand Kits Win

1

Eliminates the CSS Specificity War

Taboola's own engineering team has written extensively about CSS specificity challenges: "Even when we ensure we have no similar classes and made sure to get everything specified to the max — CSS doesn't care." Custom CSS hooks require !important overrides that break on updates.

With a brand kit, styles are generated from structured data — not hacked on top of existing CSS. No specificity conflicts, no !important battles, no surprise breakage when either party ships an update.

2

Complete Brand Fidelity — Not Approximations

Manual audits capture what a designer notices. A web crawler captures what actually exists on the page: computed font stacks with fallbacks, exact hex values at every usage context, precise spacing in pixels, SVG icon paths, and layout grid definitions.

// Manual audit might note:
"Headlines use a condensed sans-serif, probably bold"

// Brand kit JSON captures:
{
  "family": "FoundersGroteskCond",
  "weight": 600,
  "size": "32px+",
  "line_height": "1:1 ratio",
  "fallbacks": ["Arial Narrow", "Arial", "sans-serif"]
}
3

Automatic Drift Detection

Publishers redesign their sites regularly. Under the manual approach, brand drift in the Taboola feed goes undetected until someone complains. With scheduled re-crawls, the system can detect when a publisher's live styles diverge from the brand kit on file and flag differences — or auto-update the feed styling.

4

Scales Without Engineering Headcount

Taboola serves thousands of publishers. Each manual CSS customization requires dedicated engineering time. A crawler-based brand kit system can onboard a new publisher in minutes: crawl → generate JSON → apply styles. No CSS engineers needed per publisher.

5

Captures Design Tokens Beyond CSS

The brand kit JSON captures elements that CSS overrides simply cannot replicate:

SVG Icons

Peacock logo paths, social icons, play buttons, live badges — all extractable as SVG markup

Layout Patterns

Grid column ratios, card aspect ratios (16:9, 3:2), content widths, and sticky behaviors

Brand Voice

Headline casing conventions, byline formats, timestamp styles, attribution patterns

Special Indicators

LIVE badges (#CB1111), BREAKING banners, blue accent rules — complete with dimensions and colors

6

Enables Instant Prototyping & A/B Testing

With a structured brand kit, new feed layouts can be prototyped instantly by feeding the JSON into a template engine. Want to test whether NBC's condensed headlines drive more clicks than serif headlines? The brand kit has both font families with their exact specifications. A/B tests can be generated programmatically without manual CSS work.
