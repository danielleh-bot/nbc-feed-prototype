What Custom UI Modes Do Today

Font Overrides

Override headline, body, and label fonts per UI mode. Limited to pre-registered font stacks.

Color Theming

Set accent, headline, label, and background colors. No support for semantic brand palettes.

Card Layout

Choose grid vs. list, column count, card spacing. Fixed presets, not data-driven.

Thumbnail Styling

Set border-radius, aspect ratio, overlay treatments. No per-brand extraction.

Label Treatments

Configure sponsored badge, source label styles. Limited to pre-defined badge variants.

Interactive States

Hover, focus, and active states for cards. Generic defaults applied uniformly.
